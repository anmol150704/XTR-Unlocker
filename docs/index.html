ForzaTech Virtual Texture Safeguard

Titles matching Forza or Horizon switch automatically from dxgi.dll to version.dll and enable zero-overhead Streamline passthrough to avoid D3D12 virtual texture pool starvation.

  • Proxy selection: Uses version.dll instead of dxgi.dll for Forza Horizon 6 and Forza Horizon 5.
  • Streamline & NGX-OTA discovery: Recursively locates sl.interposer.dll, sl.directsr.dll, and sl.dlss*.dll across engine subdirectories without confusing Streamline plugins with nvngx_dlss.dll.
  • Texture pool protection: Skips [Anisotropy] and [Mipmap] overrides in TurboBoost so ForzaTech virtual streaming heaps remain untouched.
  • Resilient Restore: Recovers cleanly even if tracked vendor files were modified or removed outside XTR Unlocker.

Universal Frame Generation Bridge

Routes FGInput (dlssg or upscaler) to FGOutput (fsrfg, xefg, or nukems) across NVIDIA RTX 20/30/40/50, AMD RDNA, and Intel Arc GPUs.

  • Bridge backends: Supports FidelityFX Frame Generation (fsrfg), Intel XeFG (xefg), and dlssg_to_fsr3_amd_is_better.dll (nukems) with fakenvapi.dll.
  • HUD & reactive mask calibration: Enables HUDFix=true, HUDFixExtended=true, depth/motion-vector copies, and DlssReactiveMaskBias=0.45 for non-Streamline titles.
  • Dynamic DLSS presets: Sets RenderPresetForAll=13 (Preset M) on RTX 40/50 Ada and Blackwell, 11 (Preset K) on RTX 20/30 Turing and Ampere, above the static OptiScaler.ini Preset E (5) baseline.

Multi-Storefront Scanner & DLL Swapper

Scans 8 game library sources, resolves target directories even when prior DLL records do not exist, and tracks SHA-256 backups for transactional Restore recovery.

8 Supported Library Sources: Steam, GOG, Epic Games Store, Ubisoft Connect, Xbox App, Battle.net, EA App, and Manually Added folders.

  • Swap without prior records: Resolves existing asset directories, sl.interposer.dll directory, or main executable directory cleanly when zero prior swap records exist.
  • Streamline & FidelityFX SDK 2 detection: Discovers sl.interposer.dll, sl.directsr.dll, sl.dlss*.dll, amd_fidelityfx_loader_dx12.dll, amd_fidelityfx_upscaler_dx12.dll, and amd_fidelityfx_framegeneration_dx12.dll.
  • Consistent health reporting: Derives UI status directly from verified on-disk RuntimeHealthService proxy and OptiScaler.ini checks.

Quickstart, Release Artifacts & Source Build

Install a self-contained win-x64 package from GitHub Releases or compile and test directly from source with the .NET 10 SDK.

Release Packages

  • XTR-Unlocker-Setup.exe

    7-Zip SFX single-file installer extracting and launching XTR Unlocker.exe self-contained on Windows 10 19041+ / Windows 11 x64.

  • XTR-Unlocker-Release-win-x64.zip

    Standard self-contained WinUI 3 binary archive including the 18-file OptiScaler 0.9.5 runtime bundle.

  • XTR-Unlocker-Release_Portable-win-x64.zip

    Portable self-contained build storing configuration and downloaded upscaler DLLs beside the executable.

In-game OptiScaler controls: Press Insert to open the OptiScaler configuration menu and F12 to toggle Frame Generation in-game. Browse all release notes on GitHub Releases.

Source Build & Test Commands

1. Clone repository
git clone https://github.com/anmol150704/XTR-Unlocker.git
2. Run unit and integration tests
dotnet test desktop/tests/XTR.Tests/XTR.Tests.csproj -c Release
3. Run opaque-box E2E tests
dotnet test desktop/tests/XTR.E2ETests/XTR.E2ETests.csproj -c Release
4. Build self-contained ZIP and SFX installer
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1 -Configuration Release -SelfContained -PackageZip -BuildInstaller
5. Build portable ZIP archive
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1 -Configuration Release_Portable -SelfContained -PackageZip
