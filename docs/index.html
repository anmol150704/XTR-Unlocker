Engine Architecture & Capabilities

Grounded graphics systems engineering designed to eliminate stutter, ghosting, and memory bloat.

Zero-Dropout Virtual Streaming

Playground Games' ForzaTech engine relies on aggressive D3D12 virtual texture heaps. XTR forces AlwaysTrackHeaps=false, disables intrusive buffer duplication, and routes through version.dll proxy to guarantee pristine, uninterrupted roads and liveries in Forza Horizon 6 & 5.

FORZATECH HEAP SAFEGUARD

High-Velocity Anti-Ghosting Shield

At 300 km/h, road disocclusion creates heavy trailing smears. We calibrate AccAddPerFrame=0.05 and MinDisOccAcc=-0.50 to flush stale car samples instantly, while setting DisableReactiveMask=false to preserve native windshield and smoke masks.

DISOCCLUSION CLAMPING

Lock-Free Shared Memory IPC

Zero-allocation memory-mapped file (Local\XtrTelemetrySharedMem) transmits GPU utilization, 4GB VRAM budget, temperature, and frame intervals between XTR Studio and the game in <1 microsecond with zero CPU overhead.

112-BYTE PACKED STRUCT

Non-Invasive ETW Telemetry

Incorporates Intel PresentMon kernel event architecture (Microsoft-Windows-DXGI and Microsoft-Windows-D3D12). Tracks real-time 1% and 0.1% low frametimes directly from Windows kernel events without injecting hook DLLs or tripping anti-cheat.

INTEL PRESENTMON ENGINE

Active Companion Lifecycle

Monitors game launches in <500ms via WMI process watcher. Automatically elevates the game process to High priority, sets optimal GPU scheduling, and minimizes Studio to system tray to consume 0.0% background CPU.
